Airbnb Clone 🏡
A full-stack web application inspired by Airbnb that allows users to list properties, browse listings, and leave reviews. The project focuses on secure authentication, clean UI rendering, and efficient backend data handling.

🚀 Features
1.User authentication & authorization using Passport.js
2.Secure session management
3.Create, read, update, and delete property listings
4.Add and manage property reviews
5.Input validation using Joi
6.Dynamic server-side rendering using EJS
7.MongoDB database for storing users, listings, and reviews
8.Role-based access (users can only manage their own listings/reviews)

🛠️ Tech Stack
1.Backend: Node.js, Express.js
2.Frontend: EJS, HTML, CSS, Bootstrap
3.Database: MongoDB, Mongoose
4.Authentication: Passport.js
5.Validation: Joi

🔐 Authentication Flow
1.Users can register and log in securely
2.Passport.js handles authentication strategies
3.Sessions are used to maintain login state
4.Protected routes restrict unauthorized access

🧠 Key Learnings
1.Implementing secure authentication systems
2.Structuring a scalable MVC-based Node.js project
3.Working with NoSQL databases (MongoDB)
4.Building dynamic server-rendered applications
